OP Perspective 使用说明

00 Installation_安装

准备

  • 关闭 Photoshop。
  • 准备好 OP Perspective 安装包或插件文件。

操作

  1. 运行 OP Perspective 安装程序。
  2. 安装位置选择 Photoshop 的 Plug-ins 文件夹。
  3. 等待安装完成。
  4. 重新打开 Photoshop。
  5. 打开一个 Photoshop 文档。
  6. 此时应看到 OP插件面板 一同显示。

注意

  • 安装前需要关闭 Photoshop，安装完成后再重新打开 Photoshop。
  • 如果启动 Photoshop 后没有出现插件面板，按 Ctrl+F12 也无法调出插件面板，请重新安装或联系作者。

常见问题排查

  • 如果安装插件后 Photoshop 停在启动画面或自动关闭，先安装或修复 Microsoft Visual C++ 2015-2022 Redistributable x64，然后重启电脑再打开 Photoshop。
  • 官方下载地址：vc_redist.x64.exe。
  • 如果 Windows 事件查看器里显示这些错误模块：MSVCP140.dll / VCRUNTIME140.dll / VCRUNTIME140_1.dll，通常是系统缺少或需要修复 Visual C++ 运行库。
  • 如果修复运行库后仍然无法启动，请记录事件查看器中的错误模块名称、异常代码和错误模块路径后联系作者。

01 UI Panel_UI面板

入口

启动 Photoshop 并打开文档后，OP插件面板会一同显示。

面板区域

区域用途注意
顶部按钮 打开使用说明、切换中英文、开启或关闭 Overlay、关闭面板。 面板被关闭后，可以按 Ctrl+F12 重新打开。
Projection Mode 切换 Classic、Equidistant、Stereographic。 切换投影模式不会删除或重建 Object；鱼眼模式下边缘变形更明显，这是正常现象。
Camera Match 根据画面透视调整 Classic 视图。 用于匹配画面中的透视趋势。
Perspective Lines 控制透视辅助线显示和透明度。 只影响辅助线显示。
Scene Object 控制透视对象的显示和透明度。 不会直接修改 Photoshop 图层。
Curvilinear Grid 控制鱼眼模式下的曲线网格。 切换到鱼眼模式后使用。

注意

  • 面板负责显示和视图控制，不会直接修改 Photoshop 图层。
  • 如果面板被关闭，可以按 Ctrl+F12 重新打开。

02 Object_创建基础几何型

入口

按面板当前 OP 饼菜单快捷键（默认 Q）调出 OP 饼菜单。

操作

  • 未选中 Object 时，选择基础几何型会新建 Object。
  • 已选中 Object 时，选择基础几何型会切换当前 Object 的 Mesh。
  • 已选中 Object 时，按住 Ctrl 再选择基础几何型，会新建一个 Object。

复制 Object

在 Edit Mode 中按 Shift+D 可以复制当前选中的 Object。复制后会直接进入移动状态，移动到合适位置后左键或 Enter 确认。

03 编辑模式

入口

按面板当前 OP 饼菜单快捷键（默认 Q），选择下方的 Edit Mode / 编辑模式。

操作

  • 进入编辑模式后，光标会改变。
  • 进入编辑模式后，Photoshop 快捷键会被屏蔽，OP插件快捷键会生效。
  • 按 X 可以打开重置和删除菜单。
  • 按 Ctrl+Z 撤销，按 Ctrl+Shift+Z 重做。
  • 按住 Ctrl 选择 Edit Mode，会重置整个透视场景。
  • 点击空白区域、按 Esc 或右键退出编辑模式。

注意

  • 重置或删除只影响插件的透视对象，不会删除 Photoshop 图层。

04 Transform_移动、旋转、缩放

入口

  • 选中 Object。
  • 在 Edit Mode 中按 G / S / R。
  • 也可以直接拖动 OP_xCursor 或 OP_xRotateRing。

通用命令

  • 移动鼠标或输入数值进行调整。
  • 左键或 Enter 确认，右键或 Esc 取消。
  • 按 X / Y / Z 限制到对应轴；连续按两次同一个轴键，会切换到 Object 的局部坐标轴。
  • 按 Shift+X/Y/Z 排除对应轴，在平面内移动。
命令快捷键 / 控制器用途重置注意
移动 G / OP_xCursor 调整 Object 位置。 Alt+G 只改变位置，不改变 Mesh 类型。
缩放 / 调整尺寸 S 调整 Object 大小。 Alt+S Circle、Cylinder、Sphere 通常表现为半径变化；尺寸不会被压到 0。
旋转 R / OP_xRotateRing 调整 Object 方向和角度。 Alt+R 轴向约束同样适用于旋转。

05 基础几何型

入口

按面板当前 OP 饼菜单快捷键（默认 Q）打开菜单，在上方 Mesh toolbar 选择基础几何型。

通用命令

  • 选中 Object 后，可以使用移动、缩放、旋转调整位置、大小和方向。
  • 需要切换几何型时，选中 Object 后在 Mesh toolbar 重新选择。
几何型点边面功能菜单
方形（Quad） 拖动角点调整形状。 拖动边缘调整形状。 没有独立面中心控制点。 长按边缘打开；支持 Division Lines、Grid Subdivision、Inset / Outset、Rounded Corners。
圆形（Circle） 拖动 U / V 轴控制点调整胶囊形。 拖动圆环调整半径。 没有独立面中心控制点。 支持 Division Lines、Grid Subdivision、Inset / Outset。
方块（Cube） 拖动顶点调整体块角点。 拖动边调整体块。 拖动面中心调整体块。 支持 Division Lines、Grid Subdivision、Rounded Corners；Shift 规则步进，Alt 对称调整。
圆柱（Cylinder） 没有独立点控制。 拖动圆形边缘调整半径。 拖动顶部或底部中心调整高度。 根据当前可用边缘功能显示。
球体（Sphere） 没有独立点控制。 拖动外轮廓调整半径。 没有独立面中心控制点。 没有基础编辑功能菜单。
基础人物（Character） 不能编辑。 不能编辑。 不能编辑。 用于人物比例和空间参考。

06 阵列 / 旋绕 / 镜像

入口

选中 Object，进入 Edit Mode，按面板当前 OP 饼菜单快捷键（默认 Q），在右侧功能区选择 Array / Spin / Mirror。

通用行为

  • Array、Spin、Mirror 是显示参考，不会生成新的 Photoshop 图层。
  • 这三个功能一次只显示一种。
  • 支持 Quad、Circle、Cube、Cylinder、Sphere、Character。
功能显示内容可调整项适合用途
Array（阵列） 线性阵列重复参考。 方向、终点、数量。 等距排列或连续重复结构。
Spin（旋绕） 绕中心旋转重复参考。 中心、方向、角度、数量。 轮辐、花纹、放射结构。
Mirror（镜像） 镜像参考。 镜像中心和方向。 左右、上下或斜向对称结构。

07 结构相交线与X-Ray穿透显示

入口

  • Structure Intersections：从 OP 饼菜单左侧 Slot 切换；关闭时仍显示未遮挡的穿插相交线，开启后补充被遮挡的穿插结构片段。
  • X-Ray：按 Alt+Z 切换隐藏线显示。
功能用途操作注意
Object Intersections 默认显示未遮挡的穿插相交线；Structure Intersections 只补充被遮挡的穿插结构片段。 创建两个或更多 Object，调整它们的位置，让它们产生穿插；需要查看被遮挡穿插部分时，打开 OP 饼菜单并切换左侧 Structure Intersections Slot。 结构相交线只是显示参考，不能选中或拖动；补充片段复用普通 MeshWire 样式，被遮挡部分以 50% 透明度显示。
X-Ray / 隐藏线 控制被遮挡线条是否显示。 让 Photoshop 或插件编辑状态处于当前输入状态，按 Alt+Z 切换。 默认开启；菜单、控制器、Cursor 和 Pivot 不受 X-Ray 关闭影响。Structure Intersections 是 OP 饼菜单显示开关。

08 Pivot_设置操纵器锚点

功能入口用途注意
Pivot 在支持的控制点、边或 Object cursor 上按鼠标中键。 设置临时参考点，用于某些创建和变换操作。 Character 没有 Mesh 编辑用的 Pivot 目标。
Array / Spin / Mirror 中心 在支持的控制点、边或 Object cursor 上按 Ctrl+鼠标中键。 给 Array、Spin、Mirror 设置参考中心。 影响 Array、Spin、Mirror 的中心位置。

10 问题排查 FAQ

请核对弹窗顶部的“问题编号”，找到下方相同编号的条目。例如 OP-UXP-PAYLOAD 对应“插件文件缺失或内容不一致”。从弹窗打开文档时，对应标题会以蓝色高亮；只执行该条目的步骤。退出代码 1 不是问题编号；没有编号时，请看 OP-UXP-UNKNOWN。

图层像素写入模块安装失败不等于 OP Perspective 主程序安装失败；受影响的是写入 Photoshop 图层的功能。不要清空 Adobe 文件夹、修改注册数据库或反复卸载其他插件。

OP-UXP-UPIA · 找不到 Adobe 插件安装组件

  1. 从 Adobe 官方页面安装或修复 Creative Cloud Desktop。
  2. 正常打开 Creative Cloud Desktop，确认 Photoshop 可被识别。保存工作并关闭 Photoshop 后，再运行 OP Perspective 安装器一次。

Adobe Creative Cloud Desktop

OP-UXP-VERSION · 检测到未支持的插件版本

安装器已停止，避免删除未知版本或意外降级。先核对是否正在使用旧安装包；如果已经是最新安装包，不要手动删除插件，请联系作者并提供报告编号。

OP-UXP-REMOVE · 旧版本注册未能移除

保存工作并关闭 Photoshop，重新运行安装器一次。如果仍失败，停止反复安装并联系作者。多个 Photoshop 中出现同名插件不一定是冲突，不要自行清理其他版本或整个 Adobe 目录。

OP-UXP-PACKAGE · 安装包内容不一致

从官方发布页重新下载完整安装包，不要混用不同版本的辅助脚本和 CCX 文件。重新下载后仍报错，请将安装包版本和报告编号发给作者。

OP-UXP-ACCESS · 文件访问被拒绝

确认运行的是官方安装器并接受正常的管理员授权提示。查看安全软件的拦截记录；公司管理的电脑请联系管理员。不要关闭全部安全防护、取得整个 Adobe 目录的所有权或批量修改权限。

OP-UXP-PATH · 安装目录无法安全确认

安装器无法确认系统目录，或检测到目录重定向，已停止相关操作。不要自行修改系统环境变量、删除链接及其目标目录。请把问题编号和诊断日志私下发给作者；如果使用了目录迁移或企业配置，请一并说明。

OP-UXP-TIMEOUT · Adobe 安装操作超时

查看 Creative Cloud Desktop 是否正在安装或更新，等待其完成。保存工作、关闭 Photoshop 后再运行安装器一次；仍超时时，提供报告编号。超时本身不能证明是网络问题或版本冲突。

OP-UXP-ADOBE · Adobe 安装组件返回失败

保存工作并关闭 Photoshop，重新运行安装器一次。仍失败时，请把弹窗中的问题编号、报告编号及诊断日志私下发给作者，不要根据退出代码猜测原因。

OP-UXP-REGISTRATION · 未确认插件注册成功

Adobe 安装操作完成，但插件注册状态未通过检查，不能当作安装成功。确认所选 Photoshop 是需要安装的版本，并在 Creative Cloud Desktop 中检查 Photoshop 状态。不要手工修改 Adobe 注册文件；仍失败请提供报告编号。

OP-UXP-PAYLOAD · 插件文件缺失或内容不一致

检查安全软件是否隔离了安装文件，从官方发布页重新下载完整安装包并重装一次。仅有用户级和系统级两个目录不等于安装失败；请保留日志供作者确认实际文件问题，不要自行清空目录。

OP-UXP-UNKNOWN · 未知错误 / 只有退出代码 1

当前证据不足以确定原因。记录完整错误窗口和发生时间，不要按猜测更改系统设置。旧版日志未记录安装原因时，需要用带安装诊断的新安装器复现；仅凭 Companion 或 Bridge 运行日志无法确定安装失败原因。

仍未解决：联系作者

联系购买时的作者渠道，提供：OP Perspective 安装包版本、Photoshop 版本、错误编号、报告编号、截图以及已经尝试的步骤。没有报告编号时，提供发生时间和完整错误提示即可。

错误窗口会给出诊断日志和诊断报告的位置（旧版标为 Log 和 Report）。JSON 摘要不包含文档内容、激活码或令牌；完整日志可能包含本机路径和其他插件名称，请先检查后私下提供，不要直接贴到公开 GitHub Issue。此次本地生成报告不表示已经上传，也不表示作者已经收到。
